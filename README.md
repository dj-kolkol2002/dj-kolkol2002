`EVE-NG` `pfSense` `Cisco IOSvL2` `Zabbix`

`Proxmox VE` `TrueNAS / ZFS` `LEMP` `Tailscale`

A Docker-based helpdesk platform with **ticket management, real-time chat, SLA tracking, PDF reports, ClamAV scanning, and local AI features powered by Ollama**.

`Laravel 13` `Vue 3` `Docker` `Ollama`

An Ubuntu Server environment with **hardened SSH, Samba, WordPress on a LAMP stack, HTTPS, and automated rotating backups using Bash and cron**.

`Ubuntu Server` `OpenSSH` `Samba` `Bash / Cron`

`Bash` `OpenSSH` `UFW` `Log Analysis`
